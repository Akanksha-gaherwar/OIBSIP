# 🌤️ SkyCast — Weather App

## About the Project
SkyCast is a Python-based weather application built using CustomTkinter. It provides weather information through a simple, user-friendly graphical interface.

## Features
- Search weather by city name
- Display current temperature and weather conditions
- Show humidity and wind speed
- Display weather icons according to conditions
- Hourly forecast for the next 6 hours
- Daily forecast for the next 5 days
- Switch between Celsius and Fahrenheit
- Recent searches
- Welcome screen before searching
- Error handling for empty input and invalid city names
- Scrollable weather dashboard

## Technologies Used
- Python
- CustomTkinter
- Requests
- Weather APIs

## Installation

Install the required Python packages:

```bash
pip install customtkinter requests
```

## How to Run

1. Download or open the project folder.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python SkyCast_fixed.py
```

## How to Use
1. Launch the application.
2. Enter a city name in the search field.
3. Click the search button to view weather information.
4. Explore the hourly and daily forecasts.
5. Switch between Celsius and Fahrenheit as needed.

## Error Handling
SkyCast handles empty search input and invalid city names by displaying error messages in the application.

## Project Goal
The goal of SkyCast is to provide an easy and convenient way to check current weather conditions and forecasts using a graphical interface.
